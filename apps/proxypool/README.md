# Proxypool

个人代理池应用：公开来源抓取、按目标测试评价、小型随机候选队列、统一使用反馈、SQLite合批写及单页控制台。稳定性优先，最终HTTP200作为当前成功判定；验证码和业务内容有效性不在此版判定范围。

代码与方法见 [design.md](design.md)，字段／算法见 [storage.md](storage.md)，运行与验证见 [仓库README](../../README.md)。服务器独立API、内网、统一Worker与网页登录已按用户输出通过，正式来源入库和质量闭环仍在验证；旧来源适配见[来源说明](../../plugins/README.md)。旧代码的动态任意脚本发现、Redis积分及简单二态分发没有沿用。
