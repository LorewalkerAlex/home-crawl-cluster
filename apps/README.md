# 其他爬虫接入

Proxypool 是当前具体业务，其他爬虫共用 Crawlab 执行管理，不必采用 Proxypool 数据模型或自定义 runner。

用户确认按 [M01—M08 代码模块](../docs/architecture.md) 逐一审阅：Proxypool 代码分为 M03 crawler、M04 tester、M05 service、M06 web；本文件的其他业务属于 M08。每个新增业务先明确对服务器与 Worker 的 CPU、常驻／峰值内存、磁盘与 I/O、网络及共享依赖影响，再确认执行位置和限额。当前没有指定新增业务，不自动创建业务代码。

## 接入方式

有持续网页采集、解析、重试和统计需求时，优先考虑独立的标准 Scrapy 项目。已有普通 Python 抓取、清洗或解析脚本也可作为 Crawlab 程序运行；不为了统一而强制迁移。

各业务保存自己的目的、周期、输入、结果格式和业务存储。共用范围是 Crawlab 节点、任务、日志与经验证的结果接入；来源开关和代理评分属于 Proxypool。

新增业务明确执行程序、运行依赖、允许节点、结果接口、数据去重和是否保留原文即可。简单任务可抓取解析同进程；跨设备时原文先持久保存，再提交解析任务。

当前不创建未指定业务的代码，不导入旧快照中的全部项目。需要用代理的爬虫通过 Proxypool 按目标逐次获取并反馈实际结果，不直接写代理评价数据。
